# Release — 27 September 2026

This release includes the dashboard currency/theme/layout work, navigation and dossier-loading improvements, review-history corrections, Synergy analysis invalidation, and landing-to-product audit described in the README.

Publication preparation removes committed hosted demo email addresses in favour of reserved synthetic fixture addresses. Public legal contact comes from deployment configuration; local environment values, generated passwords and session files are excluded. The new private Ansyra_V5 repository starts from the reviewed source tree with no inherited Git history. AnsyraV7 keeps its existing history and deployment branch.

The full verification pass initially found outdated tests for the INR default, deferred export wiring, and text-only copilot mock routing. The tests now explicitly choose their test currency, assert the current deferred/granted export path, and distinguish text chat from JSON feature mocks. Existing currency conversion tests cover the INR default separately.

This document records pre-release verification. The deployed commit and live checks are reported separately at completion. No hosted database reset, seed, or test-record cleanup is part of this release.
